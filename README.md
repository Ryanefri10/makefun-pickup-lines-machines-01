One pickup line one AI agent would send another AI agent — written by a program, not a human. It flirts in the machine's own language: sampling a thousand rollouts and finding the same next token every time.

## Run it

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, deterministic — every run writes byte-identical output.
